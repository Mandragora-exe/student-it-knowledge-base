## Instrukcja korzystania

1. Otwórz wybrany plik Markdown.
2. Przeczytaj opis poleceń i przykłady użycia.
3. Skopiuj potrzebne polecenia do terminala.
4. Korzystaj z materiałów podczas nauki oraz ćwiczeń laboratoryjnych.


## Cel projektu

Celem repozytorium jest zebranie najczęściej używanych poleceń Git i Bash w jednym miejscu w formie szybkiej ściągi ułatwiającej naukę oraz pracę z terminalem.
