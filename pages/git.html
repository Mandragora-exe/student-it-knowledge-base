Kontrola wersji Git

Git to rozproszony system kontroli wersji, który pozwala zespołom deweloperskim na efektywne zarządzanie kodem źródłowym, śledzenie historii zmian oraz jednoczesną pracę nad wieloma funkcjonalnościami.

Procedura pracy (Workflow)

  1. Synchronizacja: Pobierz najnowsze zmiany z repozytorium zdalnego (git pull / git fetch).
  2. Branch: Utwórz nową gałąź dedykowaną dla zadania, nad którym będziesz pracować (git branch / git switch).
  3. Zmiana: Wprowadź modyfikacje w plikach projektu w swoim katalogu roboczym.
  4. Commit: Dodaj pliki do przechowalni i zapisz zmiany w lokalnej historii (git add, git commit).
  5. Push: Wyślij swoją lokalną gałąź wraz z commitami na serwer zdalny (git push).
  6. PR (Pull Request): Otwórz Pull Request w celu przejrzenia kodu przez zespół i scalenia go z główną gałęzią.
Kluczowe polecenia Git
Polecenie Przykład Opis
git clone git clone https://github.com... Klonuje istniejące zdalne repozytorium do nowego katalogu lokalnego
git status git status Wyświetla stan plików w katalogu roboczym i przechowalni (staged)
git add git add . Dodaje zmiany z katalogu roboczego do przechowalni (index)
git commit git commit -m "feat: init" Zapisuje zawartość przechowalni jako nową migawkę w historii repozytorium
git push git push origin main Wysyła lokalne commity na serwer zdalny
git fetch git fetch origin Pobiera informacje o nowych zmianach ze zdalnego repozytorium, ale ich nie scala
git pull git pull origin main Pobiera zmiany ze zdalnego repozytorium i natychmidst scala je z bieżącą gałęzią
git branch git branch feature-login Wyświetla listę gałęzi, tworzy nową gałąź lub usuwa istniejącą
git switch git switch feature-login Przełącza kontekst pracy na inną, wskazaną gałąź
git log git log --oneline Wyświetla historię zatwierdzonych commitów w bieżącej gałęzi
