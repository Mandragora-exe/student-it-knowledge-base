Interfejs wiersza poleceń .NET CLI

Interfejs wiersza poleceń (CLI) platformy .NET to wieloplatformowy produkt deweloperski służący do tworzenia, kompilowania, uruchamiania i publikowania aplikacji .NET.

Sekwencja utworzenia i uruchomienia aplikacji

# 1. Sprawdzenie zainstalowanej wersji i SDKs
dotnet --version
dotnet --list-sdks

# 2. Wyświetlenie dostępnych szablonów projektów
dotnet new list

# 3. Utworzenie nowej aplikacji konsolowej
dotnet new console -o MojaAplikacja
cd MojaAplikacja

# 4. Przywrócenie zależności (pakietów NuGet)
dotnet restore

# 5. Kompilacja projektu
dotnet build

# 6. Uruchomienie aplikacji
dotnet run

# 7. Czyszczenie danych wyjściowych kompilacji
dotnet clean
